## 🔑 AI API KEY ЖӘНЕ OCR БАПТАУ НҰСҚАУЛЫҒЫ

### 1-әдіс: Сервердегі файл арқылы баптау

`C:\flutter\ustazai\webapp\.env.local` файлын жасаңыз. Ол `.gitignore` ішінде, сондықтан Git-ке қосылмайды:

```dotenv
AI_PROVIDER=openai
AI_API_KEY=жаңа_OpenAI_API_кілті
AI_MODEL=gpt-4o-mini
OCR_PROVIDER=openai
OCR_MODEL=gpt-4o-mini
```

Файлды сақтаған соң `npm.cmd run dev` серверін қайта іске қосыңыз. Егер бөлек OCR кілті керек болса, `OCR_API_KEY` мәнін қосыңыз; әйтпесе негізгі `AI_API_KEY` қолданылады.

### 2-әдіс: Веб-интерфейс (UI) арқылы баптау

1. Браузерде **http://127.0.0.1:3107/settings** бетін ашыңыз («Баптаулар → AI және Vision сервисі»).
2. Provider ретінде **OpenAI**, Model ретінде **gpt-4o-mini** таңдаңыз.
3. Сервердегі кілтті пайдалану үшін **API key** өрісін бос қалдырыңыз. Бұл өріске енгізілген кілт сервердегі кілттен басым және осы браузерде сақталады.
4. **«Сақтау»** батырмасын басыңыз.
5. **«Байланысты тексеру»** батырмасын басып, нақты AI сұрауын тексеріңіз. **«Vision-ды тексеру»** сурет сұрауын бөлек тексереді.  
   - Сәтті болса: *«AI сервисіне қосылды»* хабарламасы шығады.
   - Қате болса: нақты себебі (лимит, қате кілт, т.б.) көрсетіледі.
6. Серверде де, браузерде де кілт болмаса ғана жүйе **Демо AI** режиміне өтеді. Бұрын браузерде **Mock AI** таңдалған болса, нақты API үшін **OpenAI** таңдаңыз.

## 🛠 Жүйедегі негізгі функциялар мен модульдер

1. **Сыныптар мен Оқушылар:**
   - 7А, 8Б, 9А сыныптары және толық оқушылар базасы.
   - CSV / XLSX арқылы жаппай импорттау мүмкіндігі.
2. **БЖБ / ТЖБ Builder және AI Generator:**
   - 8 түрлі тапсырма түрі (бір жауап, бірнеше жауап, дұрыс/бұрыс, сәйкестендіру, реттеу, қысқа жауап, ашық жауап, практикалық).
   - Критерийлер, дескрипторлар, баллдар автоматты тексеріледі.
   - Word шығару: Оқушы нұсқасы және Мұғалім нұсқасы (DOCX).
3. **Жұмысты тексеру (Grading Review):**
   - Түпнұсқа жұмысты алдын ала қарау (JPG, PNG, PDF, DOCX).
   - Vision AI арқылы қолжазбаны оқу және дескриптор бойынша бағалау.
   - Мұғалімнің ұпайды қолмен өзгертуі (override) және бағаны бекітуі.
   - Сенімділік деңгейлері: Жоғары (90-100%), Орташа (70-89%), Тексеру қажет (<70%).
4. **Жаппай тексеру (Batch Checking):**
   - Бір сыныпқа 20-30 жұмысты бірден жүктеу.
   - Файл аты мен мәтіннен оқушыны автоматты анықтау (`Aruzhan_Nurlan_BJB2.jpg`).
   - Прогресс көрсеткіші және әр жұмыс күйі: *«Аружан — 18/20 — Дайын»*, *«Данияр — Тексеру қажет»*.
5. **Аналитика және AI Analytics:**
   - Тек бекітілген жұмыстар есептеледі.
   - Орташа пайыз, орташа балл, ең жоғары/төмен, таралу, тақырып, критерий және дескриптор меңгеру графиктері.
   - AI Аналитика: нақты Фактілер мен әдістемелік Ұсыныстардың қатаң бөлінуі.
6. **Оқушы профилі және Құжаттар:**
   - Оқушының әлсіз тақырыптары бойынша Жеке тапсырма (1 жеңіл, 1 орта, 1 күрделі) және Word шығару.
   - Ата-анаға аналитикалық есеп және Word шығару.
7. **ҚМЖ (Қысқа мерзімді жоспар):**
   - Пайдаланушының нақты Word үлгісіне (`canonical-kmz.docx`) негізделген.
   - AI арқылы сабақ кезеңдерін автоматты толтыру (басы, ортасы, соңы: педагог, оқушы, бағалау, ресурстар).
   - 45 минуттық уақыт балансын тексеру (мысалы 5 + 35 + 5 = 45 мин).
   - Каноникалық кесте мен шрифт пішімін 100% сақтай отырып DOCX жасау.
8. **Document Center:**
   - ҚМЖ, БЖБ, ТЖБ, Тест, Жеке тапсырма, Ата-ана есебі — барлығы орталықта сақталады.
   - Іздеу, санат бойынша сүзгі (filter), алдын ала қарау (preview), жүктеу және жою.
9. **USTAZ Copilot:**
   - Нақты платформалық деректерге (сыныптар, 60%-дан төмен оқушылар, әлсіз тақырыптар) негізделген чат-көмекші.
